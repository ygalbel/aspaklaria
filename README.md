# Aspaklaria Mobile Site

This folder contains a mobile-friendly, static HTML copy of the Aspaklaria site.

## Contents
- Static HTML pages under letter directories (e.g., `001_ALEF/`)
- Shared styles in `site.css`
- Autocomplete index in `search-index.json`

## Local Preview
Serve the folder with any static server, for example:

```
python -m http.server 8080
```

Then open:

```
http://127.0.0.1:8080/mobile_site/
```
